# Redesign the Product Listing Page

## Objective
Create a visually distinctive product listing page for the e-commerce storefront.

## Agent role
Use the `storefront-designer` skill.

## Scope
- Product listing page and its directly related components
- Product cards, typography, spacing, imagery, filters, and sorting controls
- Responsive behavior on mobile, tablet, and desktop

## Constraints
- Inspect the existing implementation before making changes.
- Preserve existing routes, product data structures, API calls, and business logic.
- Follow the project's `CLAUDE.md` and applicable rules.
- Reuse existing dependencies and components where appropriate.
- Do not introduce fake shopping functionality or invent product data.

## Creative direction
Explore a distinctive visual approach rather than applying generic e-commerce styling. Consider the product category, target audience, imagery, typography, composition, and overall brand character.

If useful, briefly propose three genuinely different directions and recommend one before implementing it.

## Implementation and verification
Implement the chosen design in the existing project. Run the relevant checks and inspect the rendered page at representative desktop and mobile sizes when browser access is available.

## Completion report
Summarize the design decisions, changed files, checks performed, and any remaining issues.
